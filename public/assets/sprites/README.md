# CARPETA CENTRAL DE SPRITES Y ASSETS - ¿SABELOTODO?

Coloca aquí tus archivos de imagen y sprites para el juego.

## Estructura de Subcarpetas:

- `/public/sprites/logo.png` -> Logo Oficial del Juego.
- `/public/sprites/bg_official.png` -> Fondo Oficial del Juego.
- `/public/sprites/peinecito.png` -> Sprite Oficial del Peinecito.
- `/public/sprites/comodines/` -> Sprites de comodines (50/50, saltar, escudo, respuesta correcta, vida extra).
- `/public/sprites/premios/` -> Sprites de monedas, trofeos, coronas y premios.
- `/public/sprites/vidas/` -> Sprites de corazones y contadores de vidas.
- `/public/sprites/ruleta/` -> Asset o imagen oficial de la ruleta.
- `/public/sprites/decoracion/` -> Globos, estrellas, nubes, libros, adorno.
- `/public/sprites/ui/` -> Botones, marcos y paneles de interfaz.
